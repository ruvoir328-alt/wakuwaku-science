# わくわく化学

元素と周期表を、クイズで楽しく覚えられる学習アプリです。
中学生から使えるように、むずかしさを3だんかいから選べます。

**ログイン不要・登録不要。開いてすぐ遊べます。**

---

## あそびかた

### むずかしさ（3だんかい・全モード共通）

| えらべるもの | 出題される元素 |
|---|---|
| 🌱 20番まで | 水素（H）〜 カルシウム（Ca） |
| 🔷 ウランまで | 1番 〜 92番（ウラン） |
| 🌏 全部 | 1番 〜 118番 |

### モード（3つ）

| モード | 内容 |
|---|---|
| ⚗️ きほんクイズ | 原子番号・元素記号・元素名の3点セットを4択で |
| 🔬 チャレンジクイズ | 上に加えて、なかまわけ・族・常温の状態・ヒントからも出題 |
| 🗺 周期表タップ | 問題の元素が周期表のどこにあるかをタップして答える |

問題数は 10問 / 20問 / 30問 から選べます。

---

## きろく（ハイスコア）

- **むずかしさ × モード の9通りそれぞれに、個別のハイスコア**を保存します
- 正解率が上がると自己ベストを更新し、更新時には演出が出ます
- 「きろく」ページでハイスコア一覧・あそんだ回数・ぜんたいの正解率が見られます

### データの取りあつかい

- きろくは **ブラウザの localStorage（その端末の中）にのみ** 保存されます
- **サーバーへの送信は一切ありません。**外部への通信コードを持ちません
- 名前・学籍番号などの個人情報は、そもそも入力する画面がありません
- 端末・ブラウザをまたいだ引きつぎはできません。ブラウザのデータを消すと、きろくも消えます
- 「きろく」ページの「きろくをぜんぶ消す」でいつでも削除できます

## 動かしかた

ビルド不要の静的サイトです。外部ライブラリ・Webフォントも使っていません。

```bash
# そのままブラウザで index.html を開くだけでも動きます
# ローカルサーバーで見るなら:
npx http-server . -p 8080
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で
ブランチのルート（`/`）を指定してください。

---

## ファイル構成

```
index.html        画面のHTML
css/style.css     スタイル（淡いブルー／淡いグリーン基調）
js/elements.js    1〜118番の元素データ（族・周期表の位置は原子番号から計算）
js/app.js         画面遷移・出題・採点・ハイスコアの保存
```

### 元素データについて

- 「常温での状態」は、まだはっきりしていない 101番以降は出題しません
- 「なかまわけ」は、性質がはっきりしていない 104番以降は出題しません
- 「族」と周期表の位置は原子番号から計算しています
