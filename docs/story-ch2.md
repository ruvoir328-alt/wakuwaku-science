## 第9話「机の上のかごに、力ははたらいている？」（力の表し方・いろいろな力）

ねらい：力は「大きさ・向き・作用点」をもつ矢印で表す。単位は N（ニュートン）。重力 W = mg。重力を支える力として、垂直抗力・張力・弾性力（F = kx）がある。

**謎**

- 【場面1】〈画〉机の上に、リンゴの入ったかご（質量 2.0 kg）が置いてある。止まっている
- **ニュ**「このかごは、じっと止まっておる。さて、かごに力ははたらいているかな？」

**予想**

- 〈選〉力ははたらいていない／重力だけ／重力と、机が押し上げる力

**紙芝居**

- 【場面2】**リカ**「止まってるんだから、力なんてはたらいてないでしょ？」
- **ニュ**「ふむ、よい問いじゃ。では机を、そっと引きぬいてみよう」
- 【場面3】〈画〉机がなくなると、かごが落ちる
- **リカ**「え、そうなの？ 落ちた！ ずっと下に引っぱられてたんだ」
- **ニュ**「地球がものを引く力、これが『重力』じゃ。重さ W = mg。2.0 kg なら、2.0 × 9.8 = 19.6 N じゃ」
- 【場面4】〈画〉力の矢印。根もと（作用点）・長さ（大きさ）・向き
- **ニュ**「力は矢印で表す。単位は N、ニュートンと読む。…わしの名前じゃ」
- 【場面5】〈画〉机の上・ひもでつるす・ばねでつるす、の3つ。どれも上向きの矢印が 19.6 N
- **ニュ**「机が押し上げる力が『垂直抗力』、ひもが引く力が『張力』、ばねが引く力が『弾性力』じゃ。ばね定数 49 N/m のばねなら、0.40 m のびて 19.6 N になる」

**種明かし**

- 【場面6】答え：重力と、机が押し上げる力（垂直抗力）
- ポイント：止まっていても力ははたらいている。力は矢印（大きさ・向き・作用点）で表し、単位は N

**次へ**

- **ニュ**「ばねをのばして、力を目で見てみよう」→ 力の矢印シミュ／ドリル 2-2

## 第10話「2人で引っぱると、何 N？」（力の合成・分解）

ねらい：2つの力は、平行四辺形の対角線で1つの力（合力）にまとめられる。逆に、1つの力を2つの向きに分けられる（分力）。

**謎**

- 【場面1】〈画〉台車にひもを2本つけて、リカが東へ 30 N、ニュートンくんが北へ 40 N で引く
- **ニュ**「わしらが直角の向きに引っぱると、台車は何 N で引かれることになるかな？」

**予想**

- 〈選〉70 N／50 N／10 N

**紙芝居**

- 【場面2】**リカ**「30 と 40 で、70 N でしょ！」
- **ニュ**「同じ向きに引けば、そのとおり 70 N じゃ。だが、向きがちがうとどうかな？」
- 【場面3】〈画〉30 N と 40 N の矢印から平行四辺形（長方形）を描き、対角線が光る
- **ニュ**「2つの力を辺とする平行四辺形の対角線、これが『合力』じゃ」
- **リカ**「3 と 4 の直角三角形…ななめは 5！ だから 50 N？」
- 【場面4】〈画〉同じ向き 70 N、反対向き 10 N、直角 50 N の3つを並べる
- **ニュ**「向きによって合力は変わる。反対向きなら、東を正として 30 − 40 = −10、西へ 10 N じゃ」
- 【場面5】〈画〉ななめ 60° に引く 40 N の矢印を、水平と鉛直に分ける
- **ニュ**「逆に、1つの力を2つに分けることもできる。これが『分力』。水平の分力は 40 × cos60° = 20 N じゃ」

**種明かし**

- 【場面6】答え：50 N
- ポイント：合力は平行四辺形の対角線。向きがちがうと、ただの足し算にはならない

**次へ**

- **ニュ**「矢印を自分で動かして、合力を作ってみよう」→ 力の合成シミュ／ドリル 2-1

## 第11話「止まっているのは、力がないから？」（力のつりあい）

ねらい：1つの物体にはたらく力の合力が 0 のとき、力はつりあっている。つりあっていれば、止まっている物体は止まったまま。

**謎**

- 【場面1】〈画〉綱引き。ロープの真ん中の印が、ぴたりと止まっている
- **ニュ**「ロープが動かない。さて、両チームはどうしているのかな？」

**予想**

- 〈選〉どちらも力を出していない／同じ大きさの力で引き合っている／勝っているほうが少し大きい

**紙芝居**

- 【場面2】**リカ**「止まってるなら、どっちも休んでるのかな？」
- **ニュ**「顔を見てごらん。真っ赤じゃぞ」
- 【場面3】〈画〉左へ 200 N、右へ 200 N の矢印。合力 0
- **ニュ**「同じ大きさで、反対向き。合力が 0 になると、力は『つりあっている』という」
- **リカ**「え、そうなの？ 力いっぱいでも、止まってるんだ！」
- 【場面4】〈画〉植木鉢（重さ 49 N）を2本のひもで真上につるす。片方の張力 20 N
- **ニュ**「上向きの力の合計と、下向きの重力が同じになる。もう一方のひもは 49 − 20 = 29 N じゃ」
- 【場面5】〈画〉第9話の机の上のかご。重力 19.6 N と垂直抗力 19.6 N がつりあう
- **ニュ**「机の上のかごも同じじゃ。止まっているのは、力がないからではない。つりあっているからじゃ」

**種明かし**

- 【場面6】答え：同じ大きさの力で引き合っている
- ポイント：つりあい＝合力が 0。上向きの力の合計＝下向きの力の合計

**次へ**

- **ニュ**「ひもの張力を変えて、つりあいを作ってみよう」→ 力のつりあいシミュ／ドリル 2-2

## 第12話「押したら、押し返される？」（作用・反作用の法則）

ねらい：物体 A が B に力をおよぼすと、B も A に、同じ大きさで反対向きの力をおよぼす。2つの力は別々の物体にはたらく（つりあいとはちがう）。

**謎**

- 【場面1】〈画〉スケートリンク。リカ（50 kg）と、ニュートンくん（25 kg）が向かい合って立つ。リカがニュートンくんを押す
- **ニュ**「リカくんがわしを 100 N で押す。そのとき、わしがリカくんを押し返す力は？」

**予想**

- 〈選〉0 N（押していない）／100 N より小さい／ちょうど 100 N

**紙芝居**

- 【場面2】**リカ**「押してるのはわたしだけだから、ニュートンくんの力は 0 N でしょ？」
- **ニュ**「では、なぜリカくんまで後ろへすべっていくのかな？」
- 【場面3】〈画〉2人がはなれていく。リカに左向き 100 N、ニュートンくんに右向き 100 N の矢印
- **ニュ**「押すと、同じ大きさで押し返される。これが『作用・反作用の法則』。わしの第三法則じゃ！」
- 【場面4】**リカ**「でも、ニュートンくんのほうが、ずっと速くすべっていくよ？」
- **ニュ**「よい問いじゃ。力は同じでも、軽いほうが動きやすい。そのわけは、第14話のお楽しみじゃ」
- 【場面5】〈画〉つりあい（1つの物体に2つの力）と、作用・反作用（2つの物体に1つずつ）を並べる
- **ニュ**「つりあいとまちがえやすいが、作用・反作用は、別々の物体にはたらく2つの力じゃ」

**種明かし**

- 【場面6】答え：ちょうど 100 N
- ポイント：作用と反作用は、同じ大きさ・反対向き・別々の物体にはたらく

**次へ**

- **ニュ**「重さを変えて、押し合ってみよう」→ 押し合いシミュ／（ドリル：新規）

## 第13話「押すのをやめたら、止まる？」（慣性の法則）

ねらい：外から力がはたらかない（または合力が 0 の）とき、止まっている物体は止まり続け、動いている物体は等速直線運動を続ける。

**謎**

- 【場面1】〈画〉つるつるの氷の上。リカがそりを押して、秒速 2.0 m で手をはなす
- **ニュ**「まさつのない氷の上で、手をはなした。そりは、このあとどうなるかな？」

**予想**

- 〈選〉だんだん遅くなって止まる／同じ速さで進み続ける／だんだん速くなる

**紙芝居**

- 【場面2】**リカ**「押すのをやめたら、いつかは止まるでしょ？」
- **ニュ**「ふだんはそう見えるな。では、止める犯人はだれじゃ？」
- 【場面3】〈画〉床・じゅうたん・氷の上で、同じ速さで手をはなしたそり。止まるまでの長さを並べる
- **リカ**「つるつるになるほど、遠くまで行く…！」
- 【場面4】〈画〉まさつ 0 の氷。1秒ごとの位置が等間隔。v-tグラフは 2.0 m/s で水平
- **ニュ**「止める力がなければ、同じ速さで進み続ける。これが『慣性の法則』。わしの第一法則じゃ！」
- 【場面5】〈画〉電車が急ブレーキ。立っているリカが前へよろける
- **ニュ**「止まっているものは止まり続け、動いているものは動き続けようとする。この性質を『慣性』という」

**種明かし**

- 【場面6】答え：同じ速さで進み続ける
- ポイント：動き続けるのに力はいらない。止めたり、速さを変えたりするのに力がいる

**次へ**

- **ニュ**「床のまさつを変えて、すべらせてみよう」→ 氷の上のそりシミュ／（ドリル：準備中）

## 第14話「同じ力で押し続けると？」（運動の法則・運動方程式）

ねらい：物体に力がはたらくと、力の向きに加速度が生じる。加速度は力に比例し、質量に反比例する。運動方程式 ma = F。1 N は、1 kg の物体に 1 m/s² の加速度を生じさせる力。

**謎**

- 【場面1】〈画〉まさつのない床の上の台車（2.0 kg）。リカが 4.0 N の力で押し続ける
- **ニュ**「同じ力で押し続けると、台車の速さはどうなるかな？」

**予想**

- 〈選〉同じ速さで進む／だんだん速くなる／だんだん遅くなる

**紙芝居**

- 【場面2】**リカ**「同じ力なら、同じ速さでしょ？」
- **ニュ**「第13話を思い出してごらん。同じ速さで進むのに、力はいらなかったな」
- 【場面3】〈画〉0.1秒ごとの記録テープ。間隔がだんだん広がる。v-tグラフは右上がりの直線
- **リカ**「え、そうなの？ 第5話の台車と同じ、加速度が一定の運動だ！」
- 【場面4】〈画〉力を 2倍 → 加速度 2倍。質量を 2倍 → 加速度 半分
- **ニュ**「加速度は力に比例し、質量に反比例する。これが『運動の法則』。わしの第二法則じゃ！」
- 【場面5】〈画〉黒板に ma = F。2.0 × a = 4.0 → a = 2.0 m/s²
- **ニュ**「式にすると ma = F。この台車なら a = 4.0 ÷ 2.0 = 2.0 m/s²、3秒後には 6.0 m/s じゃ」
- **ニュ**「第12話で、軽いわしのほうが速くすべったのも、このためじゃ」

**種明かし**

- 【場面6】答え：だんだん速くなる（加速度 2.0 m/s²）
- ポイント：力がはたらくと加速度が生じる。運動方程式 ma = F

**次へ**

- **ニュ**「力と質量を変えて、加速度を調べよう」→ 台車を押すシミュ／ドリル 2-3

## 第15話「重いほうが、強く引っぱられるのに？」（運動方程式と落下運動）

ねらい：重力 mg は質量に比例するが、運動方程式 ma = mg より a = g となり、加速度は質量によらない。空気の抵抗があると、やがて重力とつりあって速さが一定になる（終端速度）。

**謎**

- 【場面1】〈画〉第6話の真空の筒。鉄球（2.0 kg）と羽根が並んで落ちる。リカが首をかしげる
- **リカ**「鉄球のほうが、ずっと強く地球に引っぱられてるはずなのに…」
- **ニュ**「第6話でやくそくした謎じゃな。2.0 kg の鉄球の加速度は、いくつになるかな？」

**予想**

- 〈選〉羽根より大きい／羽根と同じ 9.8 m/s²／羽根より小さい

**紙芝居**

- 【場面2】**リカ**「重力が大きいんだから、加速度も大きいはず！」
- **ニュ**「ふむ、よい問いじゃ。わしの運動方程式に聞いてみよう」
- 【場面3】〈画〉鉄球の重力 19.6 N の長い矢印。羽根の重力の短い矢印
- **ニュ**「たしかに、鉄球の重力は 2.0 × 9.8 = 19.6 N。羽根よりずっと大きい」
- 【場面4】〈画〉黒板：ma = mg → a = g。2.0 × a = 19.6 → a = 9.8
- **ニュ**「だが、重いものは動かしにくい。ma = mg の両辺を m で割ると、a = g。質量が消えるのじゃ」
- **リカ**「え、そうなの？ 重いほど強く引かれるけど、そのぶん動きにくいから、おあいこなんだ！」
- 【場面5】〈画〉空気の中の羽根。重力（下）と空気の抵抗（上）がつりあって、ゆっくり一定の速さで落ちる
- **ニュ**「空気の中では、速くなるほど抵抗が大きくなる。重力とつりあうと、速さは一定になる。これが『終端速度』じゃ」

**種明かし**

- 【場面6】答え：羽根と同じ 9.8 m/s²
- ポイント：重力は質量に比例するが、加速度は質量によらず g。第6話の謎の答え

**次へ**

- **ニュ**「質量を変えて落とし、力と加速度の矢印をくらべよう」→ 落下と運動方程式シミュ／ドリル 2-3

## 第16話「すべり出すのは、いつ？」（まさつ力）

ねらい：静止摩擦力は、押す力とつりあう大きさで変わる。その最大値が最大摩擦力 μN。すべり出したあとは動摩擦力 μ'N で、ほぼ一定。

**謎**

- 【場面1】〈画〉机の上の本（2.0 kg）。リカが横から 4.0 N で押すが、本は動かない
- **ニュ**「本は動かない。さて、このとき机が本を止めている『まさつ力』は何 N かな？（静止摩擦係数 0.50）」

**予想**

- 〈選〉0 N／4.0 N／9.8 N

**紙芝居**

- 【場面2】**リカ**「まさつ力って μN でしょ？ 0.50 × 19.6 = 9.8 N！」
- **ニュ**「計算はよくできておる。だが、本は止まっておるぞ。力はどうなっているかな？」
- 【場面3】〈画〉押す力 4.0 N（右）と、まさつ力 4.0 N（左）。つりあっている
- **ニュ**「止まっているのだから、まさつ力は押す力とつりあう 4.0 N。これが『静止摩擦力』じゃ」
- 【場面4】〈画〉押す力を 6、8、9.8 N と強くする。9.8 N をこえたところで、すべり出す
- **ニュ**「静止摩擦力には上限がある。それが『最大摩擦力』μN = 0.50 × 19.6 = 9.8 N じゃ」
- 【場面5】〈画〉すべり出したあと。まさつ力は 4.9 N で一定（動摩擦係数 0.25）
- **ニュ**「すべっているときは『動摩擦力』μ'N = 0.25 × 19.6 = 4.9 N。押す力によらず、ほぼ一定じゃ」

**種明かし**

- 【場面6】答え：4.0 N
- ポイント：静止摩擦力は押す力とつりあう（最大 μN）。すべり出すと動摩擦力 μ'N

**次へ**

- **ニュ**「押す力を少しずつ強くして、すべり出す瞬間を見よう」→ まさつ力シミュ／ドリル 2-4

## 第17話「水の中で、軽くなる？」（圧力と浮力）

ねらい：圧力 P = F ÷ S（単位 Pa）。水中の物体には、水が押し上げる浮力 F = ρVg がはたらく。浮力は、押しのけた水の重さで、全部沈めたあとは深さによらない。

**謎**

- 【場面1】〈画〉ばねばかりにつるした石（0.20 kg、体積 1.0 × 10⁻⁴ m³）。目盛りは 1.96 N。下に水そう
- **ニュ**「この石を、水の中にすっぽり沈める。ばねばかりの目盛りは、どうなるかな？」

**予想**

- 〈選〉変わらない／小さくなる／大きくなる

**紙芝居**

- 【場面2】**リカ**「石の重さは変わらないから、目盛りも変わらないでしょ？」
- **ニュ**「プールの中で、体が軽く感じたことはないかな？」
- 【場面3】〈画〉石を沈めると、目盛りが 0.98 N に。上向きの浮力の矢印
- **リカ**「え、そうなの？ 半分になった！」
- **ニュ**「水が下から押し上げる力、『浮力』じゃ。押しのけた水の重さと同じ大きさになる」
- 【場面4】〈画〉黒板：F = ρVg = 1000 × 1.0 × 10⁻⁴ × 9.8 = 0.98 N
- **ニュ**「水の密度 1000 kg/m³ に、沈んだ体積と g をかける。1.96 − 0.98 = 0.98 N が、ばねばかりの目盛りじゃ」
- 【場面5】〈画〉すっぽり沈めたまま、浅いところ・深いところに石を動かす。目盛りは 0.98 N のまま
- **リカ**「深くしても、目盛りが変わらない…」
- **ニュ**「全部沈めたら、押しのける水の体積は同じ。だから浮力も同じなのじゃ」
- 【場面6】〈画〉雪の上。ふつうのくつ（0.020 m²）と、スキー（0.25 m²）で立つリカ（重さ 490 N）
- **ニュ**「力がはたらく面積で割ったものが『圧力』P = F ÷ S。くつなら 24500 Pa、スキーなら 1960 Pa。だからスキーはしずまないのじゃ」

**種明かし**

- 【場面7】答え：小さくなる（1.96 N → 0.98 N）
- ポイント：浮力 F = ρVg は、押しのけた水の重さ。全部沈めれば、深さによらない

**次へ（2章の結び）**

- **ニュ**「これで、わしの運動の法則は全部じゃ。次の3章では、力が『仕事』をすると、何がたまるのかを調べるぞ！」→ 浮力シミュ／ドリル 2-5
