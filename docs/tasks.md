# タスク在庫リスト

ぱかちんが席を離れるときに、ここから1つ選んで Claude Code に投げるためのリスト。

## 投げ方

Claude Code にこう送るだけ：

> `docs/tasks.md` の **T-○○** をやってください。

- 作業ルールは `CLAUDE.md` のとおり（専用ブランチ → プルリクエスト。マージはしない）
- 終わったら `docs/reports/T-○○.md` に報告を書く（下の「報告の書き方」）
- 最後に、このファイルの自分のタスクの行だけ `[ ]` → `[x]` にする

## どのタスクにも共通のルール

- `main` の最新から専用ブランチを作る
- 「さわる場所」に書いてあるファイルは、公開中のもの（チャレンジモード、既存シミュ、プレイヤーなど）でも変更してよい。ただし今ある問題・動き・見た目はこわさない。それ以外のファイルはさわらない
- 問題やシミュの数値は、スッキリ割り切れるものにする。答えは全部計算して確かめ、報告に表で書く
- 向きがある量は、必ず問題文（画面）で「正の向き」を決めてから＋/−を使う
- 脚本の原本 `docs/story-ch1.md` の該当する話を読んでから作る（場面・数値・言葉をそろえる）
- スマホ幅（390px）で実際に操作して確かめる。ドリルなら10問くらい解いてみる。変えた画面のスクショを `docs/reports/T-○○/` に置く

## サイズのめやす

| 印 | 時間 | いつ投げる |
| --- | --- | --- |
| ☕ | 〜30分 | 休み時間・ちょっと席を外すとき |
| 📘 | 〜1時間 | 授業1コマ・会議のあいだ |
| 🌙 | 1時間以上 | 夜・放課後まとめて |

## 同時に投げるときの注意

同じファイルをさわるタスクは、同時に投げない（ぶつかる）。各タスクの「さわる場所」を見て、かぶっていなければ並行OK。

## 報告の書き方

`docs/reports/T-○○.md` に、この順で短く書く：

1. **やったこと**（3〜5行）
2. **スクショ**（変えた画面、スマホ幅）
3. **ぱかちんが決めること**（あれば。選択肢つきで）
4. **計算チェック**（物理の数値をさわったときだけ）
5. **さわっていないもの**

## 新しいタスクの足し方

思いついたら、いちばん近い区分に `- [ ] **T-○○　名前** サイズ` で足す。「やること」「さわる場所」を書いておくと、同時に投げられるかすぐわかる。
