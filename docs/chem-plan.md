## 3. 1章「物質の成分と構成元素」設計表（案）

※ ドリルの列は「今の化学ドリルとの対応」。1章のドリルは新しく作る（`docs/chem-story-ch1.md` の設計表では 化1-1〜化1-7）

番号は化学だけの通し番号（化学 第1話〜）。

| 話 | 狙う誤概念 | シミュレーション（案） | ドリル |
| --- | --- | --- | --- |
| 第1話 透明な水は、純粋？ | 透明できれいなら純物質 | 加熱のグラフ：純水と食塩水を加熱して温度をくらべる。純水は 100 ℃ で平らになり、食塩水は平らにならず上がり続ける | 新規（純物質・混合物を分ける） |
| 第2話 にごった水を、きれいにするには？ | ろ過すれば、とけているものも取れる | 分離の実験室：砂まじりの食塩水に、ろ過・蒸留をえらんで使う。ろ過では食塩が通りぬけ、蒸留で水だけ取り出せる | 新規（分離の方法をえらぶ） |
| 第3話 黒いインクは、1色？ | 1つの色に見えるものは1種類の物質 | ペーパークロマトグラフィー：水がしみこむと、黒インクが何色かに分かれる | 新規（分離の方法をえらぶ） |
| 第4話 骨の「カルシウム」は、金属のかたまり？ | 元素と単体は同じ意味 | 元素と単体の仕分け：「酸素」「カルシウム」が出てくる文を、元素か単体かに分ける | シンプル（元素記号）、新規（元素か単体か） |
| 第5話 ダイヤモンドと鉛筆のしんは、同じもの？ | 見た目や性質がちがえば、ちがう元素 | 同素体：炭素原子のつながり方を切りかえると、ダイヤモンド・黒鉛になる。S・C・O・P の同素体も | ハード（分類）、新規（同素体） |
| 第6話 炎の色で、中身がわかる？ | 炎の色は、燃えているもの（燃料）の色 | 炎色反応：白金線にいろいろな水溶液をつけてバーナーへ。Li 赤、Na 黄、K 赤紫、Ca 橙赤、Sr 紅、Ba 黄緑、Cu 青緑 | ハード（ヒント文）、新規（炎色反応） |
| 第7話 氷がとけている間、温度は？ | 熱し続ければ、温度はずっと上がる | 加熱曲線：氷を一定の強さで熱すると、0 ℃ と 100 ℃ で温度が止まる。そのとき粒のようすも出す | 新規（状態変化） |
| 第8話 水が水蒸気になると、粒は大きくなる？ | 気体になると、粒そのものがふくらむ | 粒子モデル：温度スライダーで粒の動きが速くなる。粒の大きさは変わらず、すきまが広がる。絶対温度 T = t + 273 も | 新規（絶対温度） |

### 各話のあらすじ（1〜2行）

- **第1話**：リカ「透明だから、ただの水でしょ？」→ 海水も透明。純物質は沸点が決まっていて、加熱すると温度が平らになる。
- **第2話**：泥と食塩の水をろ過すると、泥は取れるが、なめるとしょっぱい。とけているものはろ紙を通る → 蒸留で水だけ。
- **第3話**：水性ペンの黒をろ紙にかいて水につけると、青や赤に分かれる。黒は何種類かの色素の混合物。
- **第4話**：「骨にはカルシウムが多い」のカルシウムは元素（成分）。銀色の金属カルシウムは単体。同じ名前で2つの意味。
- **第5話**：ダイヤモンドも黒鉛も炭素だけ。つながり方がちがう＝同素体。ニュートンくんの「リンゴに聞いてみよう」は使えないので、「鉛筆に聞いてみよう」でもよい。
- **第6話**：みそ汁がふきこぼれると炎が黄色に。Na の炎色反応。花火の色も同じしくみ。
- **第7話**：氷を熱しても、とけている間は 0 ℃ のまま。熱は粒のつながりを切るのに使われる。
- **第8話**：粒は大きくならない。速く動いて、すきまが広がる。−273 ℃ で粒の動きが止まる → 絶対温度 0 K。
