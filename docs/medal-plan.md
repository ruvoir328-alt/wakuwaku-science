## 1. いまのしくみ

- シミュは8本（1章）。どれも**ミッションが3つ**（`m1` `m2` `m3`）。
- 達成すると、その行に緑の ✓ がつく。**保存はしていない**ので、ページを開き直すと全部消える。
- チャレンジモード（ドリル）には、もうメダルとトロフィーがある（T-09）。
  - メダル＝10問中 4問以上、トロフィー＝10問全部
  - もらった瞬間：メダルの絵（`medalSVG`）がポンと出る＋紙ふぶき（`confetti`）＋ジングル（`awardJingle`）
  - マイページ：単元ごとのカードに ⊙（まだ）／🥇（メダル）／🏆（トロフィー）

## 2. 案：ドリルと同じ「メダル → トロフィー」を、シミュ1本ごとに

| しるし | 条件（案） | ドリルでいうと |
| --- | --- | --- |
| ⊙ まだ | ミッション 0〜1こ | 4問未満 |
| 🥇 メダル | ミッション **2こ** 達成 | 4問以上 |
| 🏆 トロフィー | ミッション **3こ全部** 達成 | 10問全部 |

- 絵・紙ふぶき・ジングルは、ドリルとまったく同じものを使う（色も同じ。新しい色は足さない）。
- 1本ごとにしるしがつくので、マイページのカードもドリルと同じ形で並べられる。

### べつの案（くらべる用）
- **B**：メダル＝3こ全部（シミュ1本）、トロフィー＝その章のシミュ全部でメダル（章に1つ）。
  - ごほうびが重くなる。マイページは「1章のシミュ 5 / 8」のような表示になる。

## 3. どこに何を出すか

### (1) シミュの中（ミッションの下）
- ミッションを達成するたびに ✓ がつく（今と同じ）。
- メダル・トロフィーの条件を満たした**その瞬間**、ミッションの下に、ドリルと同じ「ゲット！」の箱が出る。
  - 例：「メダル ゲット！ ミッション 2 / 3」「トロフィー ゲット！ ミッション全部クリア」
  - はじめてのときだけ紙ふぶき＋ジングル。もう持っているときは、箱だけしずかに出す（ドリルと同じ）
- まだのときは、ドリルの「あと ◯ 問でメダル！」と同じ形で「あと ◯ こでメダル！」を出す。
- 「動きを少なくする」設定の端末では、紙ふぶきは出さない（ドリルと同じ）。

### (2) 開き直したとき
- 前に達成したミッションは、✓ がついたまま表示する（もう一度やってもよい）。
- いちばん上ではなく、ミッションの見出しのよこに小さく 🥇／🏆 を出す。

### (3) シミュの一覧（`sim/index.html`）
- 各シミュのカードの右に、⊙／🥇／🏆 を小さく出す。

### (4) マイページ（`physics/mypage.html`）
- 「シミュレーション」の見出しを足し、8本のカードをドリルと同じ形で並べる（⊙／🥇／🏆）。
- 上のまとめに「シミュのトロフィー ◯ / 8」を足す。

## 4. 保存のしかた

- 端末の中（localStorage）だけ。外へは送らない。
- キー：`wakuwakupub_sim_guest`（ドリルの `wakuwakupub_progress_guest` とならべた名前）
- 中身の例：

```json
{
  "freefall":   { "m1": true, "m2": true, "m3": false, "medalAt": "2026-10-23T09:00:00", "trophyAt": null },
  "speed-race": { "m1": true, "m2": true, "m3": true,  "medalAt": "…", "trophyAt": "…" }
}
```

- 名前はシミュのファイル名（`freefall` など）。章が増えても同じ形で足せる。
- **保存できない端末**（プライベートモードなど）：読み書きを全部 `try { } catch { }` で包む。保存できなくても、ミッションの ✓ とメダルの箱は、そのページの中ではふつうに出る（開き直すと消えるだけ）。
- ドリルの記録（`_progress_` と `_log_`）とは別のキーにするので、ドリルの記録はこわれない。

## 5. 作るファイル（実装のとき）
