# T-15　2-2「3力のつりあい」の答えがマイナスになるバグ

## 1. やったこと

- 2-2 の「3力のつりあい」の問題（`probEquil3`）を直した。この問題は「重さ W の物体を2本のひもで支える。一方の張力 T₁ のとき、もう一方の張力 T は？」というもの。
- **原因**：T₁ のはんいが「5 N 〜 W の 2.5 倍」になっていた。T₁ が W より大きくなると、答え T = W − T₁ がマイナスになる。直す前に2000問作ってみたら、**1249問（約6割）**が答えマイナスだった（例：W = 80 N、T₁ = 130 N → T = −50 N）。
- **直し方**：T₁ のはんいを「5 N 〜 W の半分」（5 N きざみ）にした。答え T は、いつも W の半分以上の正の数になる。
- 問題文・公式・入れる欄・動く絵・ほかの単元（2-2 の「垂直抗力」の問題もふくむ）は変えていない。変えたのは `physics/app.js` の1行だけ。

## 4. 計算チェック

直したあと、`probEquil3` で問題を **5000問** 作って調べた。

| 調べたこと | 結果 |
| --- | --- |
| T = W − T₁ になっているか | 5000問すべて ✓ |
| 答え T が正か | すべて正（いちばん小さい答え 10 N、いちばん大きい答え 145 N） |
| T₁ が W の半分以下か | すべて ✓ |
| W の種類 | 20〜150 N（10 N きざみ）の14種類が全部出た |

出た問題の例：

| 重さ W | 張力 T₁ | 答え T = W − T₁ |
| --- | --- | --- |
| 20 N | 10 N | 10 N |
| 30 N | 15 N | 15 N |
| 80 N | 25 N | 55 N |
| 100 N | 20 N | 80 N |
| 130 N | 65 N | 65 N |
| 150 N | 40 N | 110 N |

- 全単元で答えがマイナスになる問題が出ないかも、2000問ずつ作って調べた。マイナスになるのは 1-7（相対速度・逆向きに歩く。マイナスが正しい問題）だけだった。
- 2-2 を計算モードで10問解いて、10問とも正解になった。コンソールのエラーなし。
