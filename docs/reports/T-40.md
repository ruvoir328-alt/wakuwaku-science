## 1. やったこと

化学1章（T-41〜T-43）を作る前に、物理用だったしくみを化学でも使えるようにした。

- **ストーリーのプレイヤー**（`story/index.html`）
  - `story/index.html?ep=c01` で `story/chem01.js` を読むようにした（物理は今までどおり `?ep=06` → `ep06.js`）
  - 脚本ファイルに `subject: '化学基礎'` と書くと、舞台の上の名札とページの題が「わくわく化学基礎」になる（書かなければ「わくわく物理基礎」）
- **化学のドリルの土台**（新しいファイル）
  - `chemistry/drill.html` `chemistry/drill.js`：見た目は物理のチャレンジモードと同じ（同じ CSS を読む）。問題は「選ぶ問題」と「数を入れる問題」の2つの形。答えのあとに説明（クリームの枠）が出る
  - ごほうびも物理と同じ：メダル＝10問中4問以上、トロフィー＝全問正解、はじめてのときは紙ふぶきとジングル。記録は端末の中だけ（単元の番号は「化1-1」）
  - 上に「📖 化学 第◯話「…」の問題」の札。化学のストーリーから来たときは「← 第◯話のストーリーにもどる」
  - 見本として2単元を作った：**化1-1 純物質と混合物**（選ぶ問題）、**化1-7 熱運動と絶対温度**（T = t + 273 の数の問題と選ぶ問題）
- **化学の単元一覧** `chemistry/units.html`：1章の7単元（化1-2〜化1-6 は「準備中」）、メダル・トロフィーの表示、元素・周期表ドリルへのリンク
- **今の元素・周期表ドリル**（`chemistry/index.html`）：スタートのボタンの下に「📖 1章のドリル（物質の成分と構成元素）→」を1つ足しただけ（ほかは変えていない）
- `CLAUDE.md` に「化学（化学基礎）」の節、`docs/tasks.md` に「F. 化学1章」（T-40〜T-43）と、いまの地図を足した

## 3. ぱかちんが決めること

1. **化学のドリルへの入り口**：トップ画面の「化学 → チャレンジ」は今までどおり元素・周期表ドリル（`chemistry/`）に行く。そこから「1章のドリル」ボタンで単元一覧へ。
   - 選択肢：このまま／トップ画面の「チャレンジ」を単元一覧（`chemistry/units.html`）に変えて、単元一覧から元素・周期表ドリルへ（トップ画面をさわるので、別タスク）
2. **化学のマイページ**：化学のドリルの記録は、単元一覧のメダル・トロフィーで見られる。物理のマイページには出していない。
   - 選択肢：このまま／化学のマイページを作る／物理のマイページに化学の欄を足す
3. **プレイヤーの変更**：`CLAUDE.md` に「プレイヤーは勝手に変えない」とあるが、化学の話を読むためにどうしても必要だったので、T-40 として変えた（物理の話の見た目・動きは同じ）。
