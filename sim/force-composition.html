2本の力を、1本にまとめよう

やること

ミッション

  1. 直角（90°）で 30 N と 40 N を合成して、合力を見る
  2. 角度を 0° と 180° にして合成し、70 N と 10 N になるのをたしかめる
  3. 「分解」で、60° の向きの 40 N を、水平と鉛直に分ける

わかったこと

  • 2つの力の合力は、2つの力を辺とする平行四辺形の対角線
  • 向きがちがうと、合力はただの足し算にはならない（直角の 30 N と 40 N → 50 N）
  • 1つの力を2つの向きに分けられる（分力）。40 N を 60° → 水平 40 × cos60° = 20 N
チャレンジモードで計算する → 第10話のストーリーを見る
